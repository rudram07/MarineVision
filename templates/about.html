System Overview

MarineVision is an automated intelligence system engineered to address the critical challenge of detecting anthropogenic marine debris and geological acoustic anomalies on the seabed using Side-Scan Sonar (SSS) imagery. Underwater surveys produce dense waterfall acoustic datasets that are traditionally scrutinized by human hydrographers. MarineVision provides an integrated computational framework combining computer-vision preprocessing, relational metadata tracking, modular deep-learning detection interfaces, and automated PDF survey documentation.

Problems Faced

Manual inspection of underwater acoustic imagery suffers from major physical and cognitive bottlenecks:

  • Severe Acoustic Noise: Rayleigh speckle noise and high-frequency scattering obscure object contours.
  • Acoustic Shadow Complexity: Objects are identified by both bright specular reflections and dark acoustic shadows cast opposite the sonar transducer.
  • Varied Seabed Textures: Sand ripples, rock ridges, and silt deposits generate high false-positive clutter.
  • Human Operator Fatigue: Inspecting hundreds of survey kilometers manually causes inconsistent and subjective interpretation.

System Objectives

  • Accept Side-Scan Sonar images in standard formats (JPG, PNG, TIFF).
  • Validate format, size constraints (10 MB), and OpenCV pixel decoding integrity.
  • Execute acoustic contrast enhancement via CLAHE and bilateral filtering.
  • Integrate a YOLO-based deep-learning model for localizing debris targets.
  • Integrate a CNN / Autoencoder approach for detecting anomalous seabed patterns.
  • Provide synchronized side-by-side visualization of original vs processed sonar.
  • Persist audit trails, run parameters, and detections in a relational SQLite database.
  • Generate downloadable, field-ready scientific PDF analysis reports.

8-Stage System Workflow Pipeline

UML Level 2 Architecture
1. Image Upload

Operator submits SSS image via drag-and-drop or file picker.

2. Image Validation

Checks format (JPG/PNG/TIFF), 10 MB limit, and OpenCV decodability.

3. Image Preprocessing

Bilateral noise filtering, CLAHE contrast tuning, and dynamic range normalization.

4. Debris Detection

YOLO model interface evaluates bounding coordinates and class confidence.

5. Anomaly Detection

Autoencoder reconstruction error identifies unusual acoustic seabed signatures.

6. Result Visualization

Renders dual viewports, bounding overlays, and comparative highlights.

7. Database Storage

SQLite stores images, runs, detections, anomalies with ACID foreign keys.

8. PDF Report

ReportLab compiles verifiable PDF with embedded thumbnails and timings.
